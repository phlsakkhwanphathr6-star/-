# โครงงานเว็บไซต์เรียนรู้ภาษีและเครื่องคำนวณภาษี

## โครงสร้างไฟล์

- `public/index.html` — โครงหน้าและจุดติดตั้งส่วนประกอบ
- `public/parts/heading.html` — ชื่อเว็บไซต์และคำอธิบาย
- `public/parts/navigation.html` — เมนูสลับหน้า
- `public/parts/personal-tax.html` — เครื่องคำนวณภาษีบุคคล บทเรียน และแบบทดสอบ
- `public/parts/business-tax.html` — เครื่องคำนวณภาษีบริษัท/ห้างหุ้นส่วน
- `public/parts/history-admin.html` — ประวัติและหลังบ้าน
- `public/parts/disclaimer.html` — หมายเหตุการใช้งาน
- `public/js/loader.js` — โหลด HTML แต่ละส่วนมาประกอบหน้าเว็บก่อนเริ่มแอป
- `public/css/style.css` — รูปแบบ สี การจัดวาง และ responsive
- `public/js/app.js` — การทำงานหน้าเว็บ การคำนวณภาษี การเปลี่ยนแท็บ กราฟ ประวัติ และแบบทดสอบ
- `server.js` — จุดเริ่มต้น Backend (Express)
- `server/routes.js` — API สำหรับบันทึก/อ่านประวัติ และ API หลังบ้าน
- `server/db.js` — การเชื่อมต่อและสร้างฐานข้อมูล SQLite
- `data/tax-project.sqlite` — สร้างอัตโนมัติเมื่อเริ่มระบบครั้งแรก

## วิธีติดตั้งและเปิดใช้งาน

ต้องติดตั้ง Node.js LTS ก่อน จากนั้นเปิด Terminal ในโฟลเดอร์โปรเจกต์:

```bash
npm install
```

คัดลอก `.env.example` เป็น `.env` แล้วแก้ `ADMIN_TOKEN` เป็นรหัสยาวที่เดายาก จากนั้นรัน:

```bash
npm start
```

เปิด `http://localhost:3000`

## ฐานข้อมูลและ API

SQLite จะเก็บข้อมูลประวัติการคำนวณในเครื่องเซิร์ฟเวอร์:
- `GET /api/records` — อ่านประวัติของผู้ใช้ (ส่ง `x-user-key`)
- `PUT /api/records` — บันทึกประวัติของผู้ใช้ (ส่ง `x-user-key`)
- `GET /api/admin/records` — สรุปประวัติสำหรับผู้ดูแล (ส่ง `Authorization: Bearer <ADMIN_TOKEN>`)

หน้าเว็บสร้างรหัสผู้ใช้แบบสุ่มไว้ในเบราว์เซอร์ และจะซิงก์ประวัติขึ้นฐานข้อมูลเมื่อเปิดผ่านเซิร์ฟเวอร์ หากเซิร์ฟเวอร์ไม่พร้อม จะกลับไปใช้ localStorage ชั่วคราว

## การเข้าหน้าหลังบ้าน

ในหน้า “ประวัติ” ให้ดับเบิลคลิกข้อความสถานะด้านบน แล้วกรอกรหัส `ADMIN_TOKEN` ที่ตั้งไว้ใน `.env` จากนั้นส่วนหลังบ้านจะแสดงข้อมูลและปุ่มดาวน์โหลด CSV

## หมายเหตุสำคัญสำหรับส่งอาจารย์

นี่เป็นการแยกโค้ดจากไฟล์ HTML ต้นฉบับและเพิ่ม Backend + SQLite สำหรับเก็บประวัติจริงในเครื่องเซิร์ฟเวอร์ โค้ดคำนวณภาษีและข้อความความรู้ยังยึดตามต้นฉบับ ควรตรวจสอบอัตรา/เพดานภาษีกับกรมสรรพากรก่อนใช้งานจริง

ระบบผู้ใช้ในชุดนี้ใช้รหัสประจำเบราว์เซอร์ ไม่ใช่ระบบสมัครสมาชิก/รหัสผ่าน และการยืนยันผู้ดูแลเป็น token ขั้นพื้นฐาน เหมาะสำหรับต้นแบบโครงงานในเครื่องหรือการสาธิต ไม่ควรเปิดสู่สาธารณะโดยไม่เพิ่มระบบยืนยันตัวตน, CSRF/rate limiting, validation และ HTTPS
